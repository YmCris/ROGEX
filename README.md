## Descripción del Proyecto:
ROGEX es una plataforma online para poder administrar una aplicación web de video juegos,
como steam, donde tendrás 3 roles, el usuario de gamer, de empleado de empresa y de
administrador del sistema.

· Estado del proyecto: Desarrollo

## Tecnologías utilizadas:
  - Angular (Frontend (Client-Side Rendering) )
  - Java 25 (Backend (Basado en APIs RESTful (JAX RS con jersey)))
  - Apache Tomcat 11 (Servidor)
  - MySQL 8 (Gestor de bases de datos)
  - Jasper Reports (Reportes)
